# Appendix A: Affix Index

A single alphabetical reference table for every affix in scope for this
book. Pulled from `pembilas/data/affixes.json` (the prefixes/suffixes/
circumfixes) plus the infix set, which pembilas doesn't currently model.
"Status" tracks whether the linked chapter is drafted yet — this table
will be kept in sync as chapters land.

| Affix | Type | Function | Chapter | Status |
|---|---|---|---|---|
| *-an* | suffix | Result, product, or collective noun | 9 | drafted |
| *ber-* | prefix | Intransitive verb; to have or use something | 6 | drafted |
| *ber-...-an* | circumfix | Reciprocal action or plural action | 6 | drafted |
| *di-* | prefix | Passive verb (patient focus) | 5 | drafted |
| *-el-, -em-, -er-* (infixes) | infix | Small closed, mostly fossilized set (e.g. *gelembung*, *gemuruh*, *telunjuk*) | 11 | drafted |
| *-i* (bare) | suffix | Locative or repeated action on object, without *me-* | 7 | drafted |
| *-kan* (bare) | suffix | Causative or benefactive, without *me-* | 7 | drafted |
| *ke-* | prefix | Ordinal numbers; some nominals | 10 | drafted |
| *ke-...-an* | circumfix | Abstract noun or state noun (also a separate adverse-experiencer verb use — see Ch. 9) | 9 | drafted |
| *-kah* | particle | Formal yes/no question marker | 10 | drafted |
| *-lah* | suffix | Softens imperatives; adds emphasis | 10 | drafted |
| *me-* | prefix | Active verb (actor focus) | 3 | drafted |
| *me-...-i* | circumfix | Directional or repeated active verb | 4 | drafted |
| *me-...-kan* | circumfix | Causative active verb | 4 | drafted |
| *memper-* (also *memper-...-kan*, *memper-...-i*) | prefix / circumfix | "To make more X" on adjective roots; causative/intensifying on other roots | 4 | drafted |
| *-nya* | suffix | Possessive/definiteness marker, or nominaliser | 10 | drafted |
| *pe-* | prefix | Agent or instrument noun | 8 | drafted |
| *pe-...-an* | circumfix | Abstract noun or place noun | 9 | drafted |
| *per-...-an* | circumfix | Abstract or collective noun (lexically distinct from *pe-...-an*, not an allomorph of it) | 9 | drafted |
| *-pun* | particle | "Also/even"; combines with question words for "-ever" | 10 | drafted |
| *se-* | prefix | One; same; as...as | 10 | drafted |
| *-tah* | particle | Rare discourse/question particle, essentially inert in standard modern Indonesian | 10 | drafted |
| *ter-* | prefix | Accidental or stative passive (also a separate superlative use on adjective roots — see Ch. 5) | 5 | drafted |

Not in this table because it isn't an affix: **Passive Type 2**
(pronoun-fronting with a bare root, no prefix at all — Ch. 5, §5.4),
the construction Indonesian actually requires for a 1st-/2nd-person
passive agent. It's covered in Ch. 5 alongside *di-*/*ter-* because
it's the third option in the same choice, not because it belongs in
an affix index.

All chapters are now drafted (see `00-outline.md`). Note on sourcing:
*-kah*, *-pun*, and *-tah* are particles outside the 18-affix set
`pembilas/data/affixes.json` models (that file has no particle
entries), and *memper-* is outside that file's set entirely — all
four rows above are sourced from standard grammar references and
(for *-tah* and *memper-*) a live verification pass, not from that
file. See Appendix C for this book's broader reliability notes,
including which specific claims that verification pass did and didn't
confirm.
