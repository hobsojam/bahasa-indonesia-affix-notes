# Appendix B: Glossary of Linguistic Terms

Terms are listed alphabetically. Each entry links back to the chapter
where it's first used in context, if you want the fuller explanation.

**Abstract noun** — a noun naming a quality, state, or concept rather
than a physical thing (e.g. *keadilan*, "justice"). See Ch. 9.

**Actor focus** — a sentence structured around the doer of the action
as its subject; the Indonesian active voice (*me-*) is actor-focused.
See Ch. 3.

**Adjective root** — a root whose bare, unaffixed form already
functions as a descriptive predicate (e.g. *besar*, "big"). See Ch. 1,
Ch. 9.

**Affix** — a bound morpheme attached to a root to change its meaning,
category, or grammatical role. Covers prefixes, suffixes, circumfixes,
and infixes. See Ch. 1.

**Agent** — the participant performing an action (contrast
*undergoer*/*patient*). An "agent noun" (formed with *pe-*) names the
person who does something. See Ch. 8.

**Assimilation** — a sound change where one sound becomes more similar
to a neighboring sound. "Nasal assimilation" is the specific process
governing *meN-*/*peN-*. See Ch. 2.

**Circumfix** — an affix attached as a single unit both before and
after the root (e.g. *ke-...-an*). Not the same as a prefix and suffix
that merely happen to co-occur. See Ch. 1.

**Clitic** — a bound form that attaches to a host word but functions
more like a separate word grammatically than a true affix; *-nya* has
clitic-like possessive/definiteness uses. See Ch. 10.

**Dissimilation** — a sound change where one of two similar
neighboring sounds changes to become less similar (the opposite of
assimilation). The *ber-*/*ter-*/*per-* → *be-*/*te-*/*pe-* change
before an *r*-initial root is r-initial dissimilation. See Ch. 2.

**Equative** — a comparison expressing "as X as," formed in Indonesian
with *se-* on an adjective root. See Ch. 10.

**Infix** — an affix inserted inside the root itself, after its first
consonant. A small, closed, largely fossilized set in modern
Indonesian. See Ch. 11.

**Intransitive** — a verb that doesn't take a direct object. *ber-*
is the main intransitive-forming prefix. See Ch. 6.

**Kata dasar** — "root word" in Indonesian; the smallest meaningful
unit left once every affix is stripped away. See Ch. 1.

**Locative** — relating to a place, surface, or target; one function
of the *-i* suffix puts the location/target of an action in object
position. See Ch. 4.

**Nasal assimilation** — see *assimilation*.

**Nominalization** — deriving a noun from a verb or adjective root.
Covered across Ch. 8 (agent/instrument nouns) and Ch. 9 (abstract/
result nouns).

**Ordinal number** — a number indicating position in a sequence
("first," "second"...), formed in Indonesian with *ke-* on a cardinal
number root (with an irregular word for "first"). See Ch. 10.

**Particle** — a small, often untranslatable function word or
clitic-like suffix marking emphasis, question status, or concession
rather than carrying lexical meaning of its own (*-lah*, *-kah*,
*-pun*, *-tah*). See Ch. 10.

**Passive voice** — a sentence structured around the undergoer of an
action as its subject, rather than the doer. Indonesian has one
affix-free construction (Passive Type 2) and two passive-like
prefixes with different implications about the agent (Passive Type
1's *di-*, deliberate; and *ter-*, accidental/stative). See Ch. 5.

**Passive Type 1 / Passive Type 2** — traditional labels (Sneddon's
*Indonesian Reference Grammar*) for Indonesian's two passive
constructions: Type 1 is the *di-* prefix construction, used for a
3rd-person or unstated agent; Type 2 fronts the undergoer with the
agent as a bare pronoun directly before the bare root (no affix at
all), and is required for a 1st-/2nd-person agent.
See Ch. 5, §5.4.

**Patient** — see *undergoer*.

**Prefix** — an affix attached before the root. See Ch. 1.

**Reciprocal** — an action performed mutually between two or more
participants ("X each other"), one reading of the *ber-...-an*
circumfix. See Ch. 6.

**Reduplication** — repeating a root (wholly or partially) to form a
related word, e.g. for plurality or informality. Mentioned only in
passing in this book (it isn't an affix, and is out of this book's
scope) — flagged where it could otherwise be mistaken for affixation
(Ch. 10, §10.3).

**Register** — the level of formality of language use. Several
affixation patterns in this book (bare *meN-*, bare *-kan*/*-i*) are
sensitive to whether a sentence is formal/written or
casual/colloquial. See Ch. 3, Ch. 7.

**Root** — see *kata dasar*.

**Stative** — describing a state rather than an event or action. One
reading of *ter-* is stative-passive, describing the resulting state
of an event rather than the event itself. See Ch. 5.

**Suffix** — an affix attached after the root. See Ch. 1.

**Superlative** — expressing "-est" (the extreme of a comparison).
*ter-* on an adjective root forms the superlative — a distinct
function from its passive/stative use on verb roots. See Ch. 5.

**Syllable** — a unit of pronunciation built around a vowel nucleus.
Indonesian root syllables are typically (C)V(C). Relevant mainly for
locating where an infix lands. See Ch. 2.

**Transitive** — a verb that takes a direct object. *me-* verbs are
typically (though not always) transitive. See Ch. 3.

**Undergoer** — the participant an action happens *to* (as opposed to
the agent who performs it); also called the *patient*. The subject of
a passive sentence is the undergoer. See Ch. 5.

**Voice** — the grammatical system determining whether a sentence is
built around the agent (active voice) or the undergoer (passive
voice) of an action. See Ch. 3, Ch. 5.
