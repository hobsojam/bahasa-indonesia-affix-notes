# Chapter 3: Active Voice — *me-*

## 3.1 Overview

*me-* is the basic active-voice prefix: the subject is the one doing the
action (actor focus), and the sentence is built around that actor.

> Dia **menulis** surat.
> "He/she **writes** a letter."

It's the formal/written-register counterpart to using a bare root as a
verb, and the mirror image of the passive *di-* covered in Chapter 5 —
same root, same event, different focus:

> **Menulis** (active, actor focus) ↔ **ditulis** (passive, undergoer
> focus), both from the root *tulis*.

## 3.2 Forms: nasal assimilation

*me-* is never attached as plain "me" plus the root. Depending on the
root's first sound, the nasal consonant changes to match it
(assimilation), and for a few consonants the root's own initial sound is
replaced entirely. This is traditionally taught with the mnemonic that
**K, P, S, T** are the consonants that "disappear" — they get replaced
by a matching nasal rather than kept alongside one.

| Root starts with | Result | Root's initial kept? | Example |
|---|---|---|---|
| *b, f, v* | *mem-* | yes | *bantu* → **membantu** ("to help") |
| *p* | *mem-* | **no** (p dropped) | *pukul* → **memukul** ("to hit") |
| *c, j, sy, z* | *men-* | yes | *cari* → **mencari** ("to search for"); *jual* → **menjual** ("to sell") |
| *d* | *men-* | yes | *dengar* → **mendengar** ("to hear") |
| *t* | *men-* | **no** (t dropped) | *tulis* → **menulis** ("to write") |
| *g, h, kh* | *meng-* | yes | *gambar* → **menggambar** ("to draw"); *hitung* → **menghitung** ("to count") |
| *k* | *meng-* | **no** (k dropped) | *kirim* → **mengirim** ("to send") |
| vowel (*a, e, i, o, u*) | *meng-* | yes | *ambil* → **mengambil** ("to take") |
| *s* | *meny-* | **no** (s dropped) | *sapu* → **menyapu** ("to sweep") |
| *l, m, n, r, w, y, ng, ny* | *me-* (no nasal insertion) | yes | *lihat* → **melihat** ("to see"); *rasa* → **merasa** ("to feel") |

## 3.3 Usage notes

### 3.3.1 Actor focus, with an object

*me-* verbs are typically transitive — there's an object alongside the
actor-subject:

> Ani **membaca** buku itu.
> "Ani **reads** that book."

### 3.3.2 Register: formal vs. colloquial

In formal and written Indonesian, *me-* on a transitive verb is close to
obligatory. In casual spoken Indonesian, it's extremely common to drop it
and use the bare root instead:

> (formal) Saya **membaca** buku. / (casual) Saya **baca** buku.
> "I read a book."

Casual speech also has its own reduced/contracted verb forms distinct
from dropping the prefix outright (e.g. things like *nulis* for *menulis*).
That's a register-specific colloquial phenomenon with its own patterns,
not a core rule of the *me-* system itself, so it isn't covered in detail
here — just be aware you'll hear it.

### 3.3.3 Trap: *me-* alone isn't always enough

Some roots simply don't form a natural word with bare *me-* — they need
one of the extended circumfixes from Chapter 4 (*me-...-kan* or
*me-...-i*) to mean anything:

> *duduk* (to sit) → *menduduk* ✗ (not a real word)
> *duduk* + *-i* → **menduduki** ✓ "to occupy" (e.g. a position, a territory)

> *naik* (to go up) → *menaik* (marginal/limited use) 
> *naik* + *-kan* → **menaikkan** ✓ "to raise, increase, promote"
> *naik* + *-i* → **menaiki** ✓ "to ride, to board"

You can't predict from the rule in 3.2 alone whether a root needs an
extension — that's lexical, and worth double-checking a root against a
dictionary if the bare *me-* form feels off.

### 3.3.4 Trap: bare root and *me-* form can drift apart in meaning

Usually *me-* just adds formality/transitivity to the same meaning as the
bare root. But for some roots, the *me-* form has picked up a more
figurative or specialized sense while the bare root stays literal:

> *makan* (bare) — "to eat" (concrete: eating food)
> **memakan** — still "to eat/consume," but commonly seen in figurative
> or formal uses: *memakan waktu* ("to take time"), *memakan korban*
> ("to claim victims")

Don't assume *me-* + root always means exactly "the formal version of the
bare root" with zero semantic shift — check usage for roots where both
forms are common.

## 3.4 Quick reference

| | Bare root | *me-* form | *di-* form (Ch. 5) |
|---|---|---|---|
| Register | Casual/neutral | Formal, written | Formal, written |
| Focus | Actor (often implicit) | Actor (explicit, foregrounded) | Undergoer |
| Example | *tulis* | *menulis* | *ditulis* |
