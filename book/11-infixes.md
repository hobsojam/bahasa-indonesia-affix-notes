# Chapter 11: Infixes — *-el-*, *-er-*, *-em-*

## 11.1 Overview

Indonesian has a small set of **infixes** — affixes inserted inside the
root rather than before or after it. Unlike every other affix in this
book, the infix set is **closed and unproductive** in modern
Indonesian: you can't take an arbitrary root and infix it to coin a new
word. The handful of words that contain one are inherited, fossilized
forms, worth recognizing but not worth trying to reproduce.

Because this is a closed, fossilized set rather than a live grammatical
process, it also sits outside what `pembilas/data/affixes.json` models
at all (per that file's own scope, and this book's Appendix A) — the
material in this chapter is sourced directly from standard grammar
references, not cross-checked against the reference project used
elsewhere in this book.

| Infix | Inserted after root's first consonant | Example |
|---|---|---|
| *-el-* | yes | *g* + **-el-** + *embung* → **gelembung** ("bubble") |
| *-er-* | yes | *g* + **-er-** + *igi* → **gerigi** ("serration, row of teeth-like notches") |
| *-em-* | yes | *g* + **-em-** + *uruh* → **gemuruh** ("rumbling, roaring") |

## 11.2 Where the infix lands

All three infixes slot in at the same position: right after the root's
first consonant, before the vowel that starts the first syllable
(§2.4). Two more attested examples:

> *tunjuk* ("to point, show") → **telunjuk** ("index finger") — *t* +
> **-el-** + *unjuk*
> *gigi* ("teeth") → **gerigi** ("serrated, toothed edge") — *g* +
> **-er-** + *igi*

## 11.3 What meaning, if any, these infixes carry

Unlike the productive affixes elsewhere in this book, these infixes
don't carry one single, extractable meaning you can apply predictably.
At most, a rough pattern (not a rule) connects some of them to
intensity, repetition, or a resemblance/diminutive sense: *gerigi*
("serration") plausibly relates to *gigi* ("teeth") via a sense of
repeated, teeth-like notches, and *gemuruh* ("rumbling") plausibly
relates to *guruh* ("thunder") via a sense of repeated or extended
sound. Treat these connections as historical/etymological background,
not as something you can use to derive a new word's meaning — the
synchronic (present-day) Indonesian speaker encounters these as single
fossilized vocabulary items, not as root-plus-infix combinations they
actively parse.

## 11.4 Trap: don't go looking for infixes in ordinary vocabulary

Because the set is this small and closed, the biggest practical risk
isn't misusing an infix — it's **false positives**: spotting a
coincidental *-er-*, *-el-*, or *-em-* string inside an unrelated word
and assuming it's this infix at work. It isn't, unless the word is one
of this closed set (or one documented alongside it in a reference
grammar). A word like *kemeja* ("shirt") is not *k* + *-em-* + *eja* —
it's an unanalyzable loanword (from Portuguese, via Malay), not an
infixed root.

## Practice

Identify the infix and the root it's built on for each word, and give
its gloss:

1. *gelembung* ("bubble")
2. *telunjuk* ("index finger")
3. *gemuruh* ("rumbling, roaring")

<details>
<summary>Answer key</summary>

1. *-el-* infixed into *gembung* ("to swell, puff up") → **gelembung**,
   "bubble."
2. *-el-* infixed into *tunjuk* ("to point, show") → **telunjuk**,
   "index finger" (the finger used for pointing).
3. *-em-* infixed into *guruh* ("thunder, rumble") → **gemuruh**,
   "rumbling, roaring."
